# Ghufran Mohamed — Full Stack Developer Portfolio

A React + TypeScript + Vite portfolio based on Ghufran’s provided CV and publicly accessible GitHub repositories.

## Run locally
```bash
npm install
npm run dev
```

## Publish
Deploy to Vercel (framework preset: Vite) or another static host. Build command: `npm run build`; output directory: `dist`.

## Update projects
Edit `projects` in `src/main.tsx`. The Reboot01 Gitea profile (`https://learn.reboot01.com/git/gmohamme`) requires authentication, so its complete list of repositories could not be retrieved. Add verified project details and screenshots when available.

Includes the submitted CV as a downloadable PDF.
